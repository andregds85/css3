Estilo de Borda CSS

A propriedade especifica que tipo de borda deve ser exibida. border-style

Os seguintes valores são permitidos:

dotted - Define uma borda pontilhada

dashed - Define uma borda tracejada

solid - Define uma borda sólida

double - Define uma borda dupla

groove - Define uma borda sulcada 3D. O efeito depende do valor da cor da borda

ridge - Define uma borda triada com ranhuras 3D. O efeito depende do valor da cor da borda

inset - Define uma borda 3D embutida. O efeito depende do valor da cor da borda

outset - Define uma borda inicial 3D. O efeito depende do valor da cor da borda

none - Não define fronteira

hidden - Define uma borda oculta

Estilizando Botões em HTML


As propriedades CSS mais comuns para estilizar botões são:

background-color - define a cor de fundo de um botão

color - define a cor do texto de um botão

border - define a borda de um botão

padding - define o espaço entre o texto e a borda de um botão

border-radius - adiciona cantos arredondados a um botão

box-shadow - adiciona sombras a um botão

text-align - centraliza o texto de um botão

font-size - define o tamanho da fonte do texto em um botão

text-decoration - remove o sublinhado para elementos usados como botões

cursor - muda o cursor do mouse ao passar o mouse sobre o botão

Os botões normalmente são criados com o elemento HTML, o elemento ou um elemento estilizado como um botão.
